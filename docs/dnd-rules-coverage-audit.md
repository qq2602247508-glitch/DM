# D&D 资料库 → 规则积木覆盖审计

更新时间：2026-08-02

## 最新执行状态（2026-08-01）

本轮已完成用户要求的两类“可安全自动化”路径：战斗法术效果现在会写入并执行 `CombatEffect`；玩家可以通过 `/api/v1/player-room/me/combat/cast` 对自身或友方施放结构化治疗、增益、抗性与状态效果，并由服务端校验阵营、距离、动作经济、法术环阶和法术位。明确的重复伤害/治疗已接入回合边界执行器。

当前 753 条核心法术的最新编译器计划指标为 `475 exact / 38 partial / 240 manual`（按当前本地资料库重新统计）。其中 `manual` 主要是叙事、传送、创造、变形、反制或多分支文本；`partial` 仍有未决字段。这个数字不是“475 个法术完全无需 DM/玩家输入”，伤害和治疗的最终骰值仍按设计由玩家或 DM 提供。

剩余 42 条含未完全支持的重复状态/修正效果，292 条含 DM 裁定文字，8 条伤害字段不安全，1 条升环基础环阶缺失。PR/探索路径已对光暗、侦测、定位、陷阱、物件状态、语言/传讯和物资类效果提供结构化 DM 确认执行；复杂传送、创造物、变形、反制和多分支仍不冒充全自动。

这份审计区分三个概念：

1. 资料存在：本地 JSON / HTML 里有原文。
2. 结构化：原文被编译成目标、资源、距离、区域、伤害、治疗、豁免、状态、移动、召唤等积木。
3. 自动结算：战斗引擎可以在不依赖 DM 临时解释的情况下执行。

“资料存在”不等于“可以自动结算”。未知数字、模糊文本、多个分支选项和 DM 裁定不能被默认值替代。

法术规则计划当前约为（这是“编译器计划”指标，不是端到端自动施法覆盖率）：

- 最新运行统计为 475 条 `exact` / 结构化计划无未决原因；
- 38 条 `partial` / 有部分积木但仍有未决项；
- 240 条 `manual` / 已有目标、资源、持续时间或文字规则，但不能安全地假装成全自动。

真正的战斗执行边界更窄：当前后端可靠自动处理的是“最终伤害/治疗数值已由玩家或 DM 给出后”的 HP、临时 HP、抗性、易伤、免疫和基础动作经济；攻击检定、豁免、状态持续、多目标、区域几何、召唤生命周期等仍不是完整的单事务执行器。因此不能把上面的 347 条称为“所有法术已完整自动”。

怪物防御方面，1,111 个怪物原子中目前有 53 个明确解析出伤害抗性、易伤或免疫；这些字段会生成 `DefenseBlock`，并在图鉴实例化为场景/战斗单位时带入 `Combatant`。伤害类型统一归一化为 `acid`、`bludgeoning`、`cold`、`fire`、`force`、`lightning`、`necrotic`、`piercing`、`poison`、`psychic`、`radiant`、`slashing`、`thunder`；抗性减半向下取整、易伤翻倍、免疫归零，抗性与易伤同时存在时相互抵消。条件抗性或“非魔法武器”等带前置条件的文字仍不会被强行简化。

本轮又补了三条安全边界：`触碰/接触` 编译为 5 尺，明确的 `1里` 编译为 5,280 尺，`特殊/视野` 等仍保持未知；“获得临时生命值”会生成 `HealBlock.temporary_hp=true`，不再伪装成普通治疗；升级预览只有在战役启用 `multiclassing` 扩展时才允许新增多职业，DM 覆盖会留下审计警告。

这不是失败数据。大量法术本身就是叙事、传送、创造物、变形、反制或多分支选择，必须先扩充积木类型和执行器，不能把它们压成一个伤害骰。

## 已实现的扩展基础

`backend/src/dnd_dm_assistant/domain/rule_extensions.py` 是唯一的扩展白名单。每个扩展声明：

- 稳定 key、中文名称、类别和本地资料来源；
- 是否需要旧版/变体开关；
- 冲突关系，例如固定先攻与阵营先攻不能同时开；
- `full` / `partial` / `dm_only` 自动化等级；
- 生成到本团图鉴的 `entry_type=rule` 原子及 `rules_json.rule_plan`。

创建战役时从 `/api/v1/rules/extensions` 取得选项，保存到 `campaigns.enabled_rule_extensions`。车卡接口 `/api/v1/rules/character-options?campaign_id=...` 会返回当前团启用的扩展，DM 和玩家车卡页都显示来源与自动化等级。

## 不能接受的“修复”

- 没有范围就写成 5 尺；
- 没有伤害骰就写成 `1d6`；
- 从召唤物 stat block 串页里取伤害、范围或 DC；
- 把“需要 DM 选择”的伤害、目标数、分支、资源消耗伪装成固定数值；
- 把所有本地规则正文一次性默认打开。
