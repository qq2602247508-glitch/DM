## 本轮已新增的真实入口

- 怪物动作解析保留 `action_type`、充能区间、多重攻击次数、传奇动作消耗。
- `POST /api/v1/campaigns/{campaign_id}/combats/{combat_id}/monster-ai/preview` 根据当前战斗快照选择敌对目标和可用动作；它只生成可审计的 DM 确认计划，不自行猜命中、范围、豁免或伤害。
- 怪物全自动回合沿用 `TurnCommandConsole`/战斗地图现有执行链：先寻路，再攻击；需要玩家豁免或检定时写入待处理请求并暂停，玩家确认后再恢复推进。充能动作的 `recharge_available` 由确认接口持久化，动作台提供 DM 充能骰入口。
- 标准动作通过战斗确认接口真实消费动作/反应/速度；使用物品会校验角色拥有权并扣减数量，物件互动会校验 SceneObject 版本并写回物件状态。
- 法术执行路径支持 `target_ids`、逐目标豁免结果、半伤/无伤、友军/敌军关系、区域筛选和真实 HP/状态事务；预览与确认仍分离。
- 社交确认路径会写入 NPC 态度/记忆并推进世界时钟；探索线仍在继续扩充追逐、陷阱、毒病、Downtime 和环境危害。

## 防止“文字完成”的统一规则

1. 没有明确数值或目标范围时，返回待 DM 确认，不默认 5 尺、1d6 或自动成功。
2. 解析字段必须进入执行路径，至少改变 HP、资源、位置、条件、先攻或世界时钟之一。
3. 预览不能写状态；确认必须可幂等，并校验参与者/角色版本。
4. 不能自动化的复杂规则保留结构化提案和原文证据，但不计入完整自动化覆盖率。
