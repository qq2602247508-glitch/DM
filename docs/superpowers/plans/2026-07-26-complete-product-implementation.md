# 本地 D&D 5e DM 助手完整实施计划

> 本计划覆盖已确认的全部九批功能。每一批都必须独立完成迁移、后端事务、
> 前端交互、自动化测试和浏览器烟测，不能只留下占位入口。

**目标：** 把现有本地 DM 助手扩展成以 D&D 5e 2024 为默认规则、以 SQLite
为事实源、所有重要变化由 DM 确认、支持遭遇—战斗—探索—成长—叙事完整闭环
的本地战役操作系统。

**架构原则：** 后端事务服务负责跨实体写入，前端只提交草案或确认命令；AI
只生成结构化草案，不直接修改事实。每次跨实体操作记录审计、幂等键和可撤销
快照。所有规则结果保留规则年份、来源和计算解释。

**技术栈：** FastAPI、SQLAlchemy、Alembic、SQLite、Pydantic、React、
TypeScript、TanStack Query、Tailwind、Vitest、Pytest、Ollama。

---

   `qq2602247508-glitch/DM`。

   `node_modules`、构建和测试产物。

验收：

- 仓库中没有凭据、数据库、模型、向量或 DND5eChm 原文。

## 批次 2：战斗规则核心

后端实体：

- `combat_actions`
- `combat_effects`
- `combat_reinforcements`
- `death_saves`
- 战斗员实例补充临时生命、最大生命下降、反应、专注与位置版本。

规则服务：

- 攻击检定、豁免、优势/劣势、重击。
- 伤害/治疗、抗性、易伤、免疫、临时生命。
- 状态持续时间、回合开始/结束、专注检定和死亡豁免。
- 动作、附赠动作、反应、移动、传奇和巢穴动作。
- 经验、战利品、状态回写的一次性结算事务。

前端：

- 战斗员卡明确显示 AC、HP、速度、先攻、豁免和资源名称。
- 动作选择 → 目标 → 掷骰 → 预览 → DM 确认 → 结果日志。
- 回合资源、状态、专注、死亡豁免和增援面板。
- 结算页显示经验、战利品、死亡/撤退和待回写状态。

测试：

- 规则函数金样；重复确认幂等；事务回滚；结算锁。
- 战斗主要路径组件测试和浏览器烟测。

## 批次 3：休息、生命骰与资源池

后端实体：

- `resource_pools`
- `rest_records`
- `rest_recovery_entries`

规则服务：

- 短休、长休、生命骰、恢复上限和中断休息。
- 职业/种族/专长资源按短休、长休或每日恢复。
- 法术位、疲乏、死亡豁免和命中骰的恢复解释。

前端：

- 角色卡统一资源面板。
- 推进台发起团队休息，逐项预览恢复与世界时间变化。
- DM 可排除角色、修改消耗生命骰并确认。

测试：

- 各恢复来源、上限、重复确认、休息中断和时间推进。

## 批次 4：法术、装备、同调与经济

后端实体：

- `known_spells`、`prepared_spells`
- `equipment_instances`、`attunements`
- `wallets`、`currency_transactions`
- `shop_inventories`

规则服务：

- 已知/准备法术、施法属性、法术位、升环、专注、仪式和材料。
- 装备/卸下、护甲 AC、武器精通、弹药、充能、消耗品、同调和诅咒。
- 铜银金铂精确换算，购买、出售、分账、队伍财产和价格修正。

前端：

- 角色卡法术页与装备页。
- 战斗中可查看并消耗法术位、弹药和物品充能。
- 商店交易先预览余额、负重和库存变化，再由 DM 确认。

测试：

- 法术资源、AC/负重、同调上限、货币守恒与交易回滚。

## 批次 5：场景网格、探索与世界时间

后端实体：

- `scene_grids`、`scene_tokens`、`scene_objects`
- `visibility_states`
- `world_clock`、`exploration_turns`、`travel_legs`

规则服务：

- 单位位置、体型占格、移动距离、困难地形、攀爬/游泳/飞行。
- 门、掩体、陷阱、光源、黑暗视觉、视线和范围模板。
- 探索轮、搜寻、开锁、拾取、随机遭遇钟。
- 旅行速度、守夜、天气、口粮、疲乏和地点间时间。

前端：

- 场景创建时生成并编辑持久网格。
- 战斗加载同一场景网格和对象，不复制静态图片。
- 网格拖动、距离/范围、掩护、可见性和 DM 私密层。

测试：

- 网格几何、路径消耗、视线、对象互动、时间与旅行金样。

## 批次 6：推进台、任务、关系、阵营与停工期

后端实体：

- `story_beats`、`quest_objectives`
- `npc_memories`、`faction_reputations`
- `clue_discoveries`、`downtime_activities`

规则服务：

- 剧情节点、分支、目标、失败/部分完成/超时和里程碑。
- NPC 态度、承诺、谎言、欠债、记忆和阵营声望。
- 谈判、追逐、潜行、调查和技能挑战。
- 停工期、制作、训练、研究和持续费用。

前端：

- 推进建议明确展示“建议 → 事实变化草案”。
- 当前场景、在场人物、任务目标、线索、关系和时间统一状态栏。
- 场次检查点、总结、前情提要和未解决事项。

测试：

- 分支一致性、关系/声望边界、任务奖励幂等和检查点恢复。

## 批次 7：完整职业成长库与形态/伙伴

规则数据：

- 2024 十二核心职业 1–20 级完整成长。
- 子职业等级、职业特性、属性提升/专长、武器精通和法术进度。
- 种族、背景、专长、技能熟练、工具和语言选择。
- 多职业前置条件、熟练、法术位合并和生命骰。
- 召唤物、魔宠、动物伙伴、荒野形态和变身模板。

角色创建：

- 展示全部可用职业、种族和背景，不依赖少量提示。
- 每步显示来源、获得内容、冲突和未完成选择。
- 支持手填、表格导入/导出和可审核的图片识别草稿。

升级：

- 生命值固定值或掷生命骰。
- 每一级的必选/可选特性、法术、专长、属性和资源变化。
- 先预览差异，确认后一次性更新；保存升级选择历史。

测试：

- 每个职业关键等级金样、全等级完整性、多职业组合和导入导出往返。

## 批次 8：玩家视图与本机桌面呈现

后端：

- 专用公开 DTO 与查询，数据库层过滤 DM 秘密。
- `handouts` 与 `player_action_requests`。
- 玩家请求只能形成待确认操作，不直接改角色事实。

前端：

- 玩家投屏：公开地图、先攻、公开状态、讲义和共享日志。
- 单角色视图：角色卡、背包、法术、资源和行动申请。
- 战争迷雾与 DM 私密图层绝不通过玩家 API 返回。

测试：

- API 隐私契约测试、玩家请求权限测试和投屏浏览器测试。

## 批次 9：AI、内容、房规、备份与正式交付

AI 与内容：

- 所有生成器使用严格 schema、一次有限修复和人工确认。
- 2024/Legacy/第三方/未知内容分类、去重和来源引用。
- 房规作为显式覆盖层，计算结果显示覆盖前后差异。
- 本地模型上下文压缩、缓存、超时和降级。

可靠性：

- 通用撤销依赖检查、审计浏览器和操作版本冲突。
- 自动备份清单、恢复点、旧版本升级和只读安全模式。
- 启动器诊断数据库、迁移、模型、向量索引和端口。
- 全链路 E2E、迁移回归、性能预算和崩溃恢复演练。

正式验收：

- 从空库建战役、车卡、备团、推进、探索、战斗、结算、休息、任务和升级。
- 从现有本地库升级不丢数据。
- 断开网络仍可运行核心流程。
- 玩家接口无法得到任何 DM 私密字段。
- 全部写操作可审计；满足前置条件的操作可撤销。
