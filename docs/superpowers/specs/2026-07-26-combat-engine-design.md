# 战斗规则引擎设计

## 目标

把现有先攻、HP和状态追踪器升级为可解释但不越权的 D&D 5e 2024
战斗执行器。系统自动计算确定性规则，掷骰与永久后果仍由DM控制。

## 战斗生命周期

1. 从场景创建战斗，复制场景网格和实例状态。
2. 选择参战者、部署位置、突袭状态和初始资源。
3. 掷先攻并处理同值排序；DM可覆盖。
4. 按回合执行移动、动作、附赠动作、反应和自由互动。
5. 回合结束处理持续效果、豁免、专注和冷却。
6. 轮次结束处理巢穴动作、环境效果和增援。
7. 达成胜利、撤退、谈判或其他结束条件。
8. DM审核经验、战利品、伤亡和永久状态后结算。

## 数据结构

### `combatants`

增加：

- `temporary_hp`
- `death_save_successes`, `death_save_failures`
- `concentration_effect_id`
- `movement_remaining_ft`
- `action_available`, `bonus_action_available`, `reaction_available`
- `surprised`, `stable`, `hidden`
- `position_x`, `position_y`, `position_z`
- `size`, `reach_ft`
- `resistances`, `immunities`, `vulnerabilities`
- `snapshot_json`：进入战斗时的规则快照

### `combat_actions`

记录每次动作：

- 行动者、目标、动作类型、规则来源。
- 命中/豁免公式和掷骰结果。
- 原始伤害、类型、抗性修正和最终变化。
- 资源消耗。
- 是否由DM覆盖及覆盖原因。
- 可逆操作引用。

### `combat_effects`

- 状态、增益、减益、光环和持续伤害。
- 来源实体和来源动作。
- 持续单位：回合、轮次、分钟、专注、直到豁免成功。
- 保存DC、豁免属性、触发时点。
- 叠加规则和结束条件。

### `combat_reinforcements`

- 目标轮次、实体、数量、部署区域和触发条件。
- `scheduled`, `ready`, `deployed`, `cancelled` 状态。

## 规则计算

### 攻击与豁免

- 命中：d20 + 属性调整值 + 熟练加值 + 其他修正。
- 优势与劣势相互抵消，不累加多个骰。
- 重击按2024规则和具体能力计算。
- 豁免DC由动作或施法数据提供。
- 所有计算展开显示，DM可修改最终结果。

### 伤害与生命

处理顺序：

1. 原始伤害骰。
2. 免疫。
3. 抗性或易伤。
4. 临时生命值。
5. 当前生命值。
6. 0 HP后的死亡规则。

同一伤害事件不同时应用抗性和易伤；具体特性覆盖通用规则。

### 死亡与稳定

- 0 HP进入倒地和失能状态。
- 回合开始提示死亡豁免。
- 记录成功、失败、自然1和自然20。
- 受到伤害增加失败；重击按规则处理。
- 三次成功稳定，三次失败进入“等待DM确认死亡”。
- 系统绝不自动把角色永久标记死亡。

### 专注

- 同一施法者只能维持一个专注效果。
- 开始新专注前预览将结束的旧效果。
- 受伤时生成体质豁免请求和DC。
- 失能、死亡或规则指定事件自动结束专注。

### 动作经济

- 每回合重置移动、动作、附赠动作。
- 反应在自身回合开始恢复。
- 疾走、撤离、闪避、协助、躲藏、预备和搜索为标准动作。
- 预备动作绑定触发条件并消耗反应。
- 借机攻击由离开威胁范围触发提示，不自动执行。

## 特殊战斗

- 大型生物占格与触及距离。
- 坐骑与骑乘状态。
- 飞行、悬浮、攀爬、游泳和倒地。
- 群怪按独立实例或同类分组先攻。
- 传奇动作在其他生物回合结束时提示。
- 巢穴动作固定先攻位或规则指定时点。
- 阶段首领在阈值或事件触发后切换能力快照。
- 召唤物记录控制者、持续时间和共享/独立先攻。
- 非致命攻击、投降、撤退和谈判可结束遭遇。

## 结算

- 经验值使用怪物基础XP，不使用仅用于难度评估的调整XP。
- 支持平均、自定义和不参与分配。
- 支持击败、驱散、谈判、绕过等解决方式。
- 战利品生成后先进入结算预览，再分配到角色或队伍仓库。
- 临时战斗状态按规则清除；持续状态同步回角色/NPC/怪物实例。
- 结算和经验发放在一个事务内，重复提交幂等。

## UI

- 顶部：轮次、当前回合、场景、胜利条件和难度解释。
- 左侧：先攻序列、HP、AC、临时HP、专注和反应。
- 中央：持久化网格。
- 右侧：选中单位的动作、法术、资源和状态。
- 底部：行动日志、掷骰解释、待处理触发和DM覆盖。
- “简洁模式”只显示先攻、HP和常用动作。
- “规则模式”展开完整计算与引用。

## 错误和冲突

- 资源不足时阻止执行并说明缺少什么。
- 目标已失效时不执行部分动作。
- 并发版本冲突时刷新该战斗，不覆盖新状态。
- 不识别的自定义动作允许DM录入结果，但标记为手动。
- 规则证据不足时不给出伪确定答案。

## 验收

- 同一伤害事件能正确处理临时HP、抗性和0HP。
- 专注切换和受伤检定完整。
- 死亡豁免不会自动永久杀死角色。
- 回合资源和反应在正确时点恢复。
- 结算事务不能重复发经验或战利品。
- 战斗刷新后位置、效果、回合和日志全部恢复。
